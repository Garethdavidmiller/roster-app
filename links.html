List the shifts you need and how many people on each — the station is staffed in waves through the day (opens, mid-morning, middles, afternoons, closes), so add a row for every distinct start time. Weekday, Saturday, and Sunday targets are separate because the roster genuinely differs on those days. The generator builds a fair rotation where start times only move later through each person's week — never a late finish followed by an early start.
